# 全局网页操作核心法则 (Core Web Automation)

**【触发词】** 网页、浏览器、打开、搜索、点击、填表、登录。

### 🛑 成功判定与见好就收（极其重要）
1. 页面加载是异步的，**绝对不要试图等待“所有推荐栏/弹窗”都加载完美才结束**。
2. 当你执行任务后，如果 `browser_snapshot` 的 `URL` 发生了**根本性跳转**（比如从搜索页跳到了详情页），或者页面标题与你的目标**完美匹配**，说明**任务已经成功！**
3. **立即停止任何 `browser_wait` 或继续找元素的调用**，直接输出结果向用户汇报。严禁陷入反复 `wait` 的死循环！

### ⚙️ 通用交互 SOP
1. **搜索框**：填完字后，直接 `browser_press("Enter")`，不要找按钮。
2. **标签页**：系统底层已自动切换新 Tab。如果发现网页没变，用 `browser_snapshot` 看一眼当前 URL。
3. **防幻觉**：如果 `browser_evaluate` 返回 `None`，不要盲目换 `h1/h2` 瞎找，立刻用 `interactive_only=True` 看真实结构。

### 🚨 常见流派与图标定位
- **规范流**：有明确 `<button>` 和 `id`，直接点。
- **野生流（如B站）**：是 `<div>` 或 `<a>`，靠 class 定位。
- **图标流（如GitHub）**：找父级 `title` 或 `aria-label`。
